Классик 19 — «Сказка о маленьком Ёжике»

Файлы для GitHub Pages:
- index.html
- assets/cover-1.webp, assets/cover-2.webp, assets/cover-3.webp

Аудио остаётся по прямым ссылкам в облачном хранилище selstorage.ru.
MP3 не нужно загружать на GitHub.

Установка:
1. Создайте папку classic19 в репозитории ErofeevaVA/games.
2. Поместите в неё index.html и папку assets.
3. Откройте https://erofeevava.github.io/games/classic19/index.html
4. В HTML-элемент Zero Block попапа классика 19 вставьте содержимое tilda-popup-19.html.
5. Не загружайте файл tilda-popup-19.html на GitHub (он только для Tilda).

Возможности: play/pause; одна активная запись; ±15 секунд;
ползунок перемотки, отметки времени; адаптация для мобильного;
полноэкранный попап и восстановление прокрутки.

Важно: доступность аудиофайлов по внешним ссылкам нужно проверить
на опубликованном сайте — автоматическая проверка сервера selstorage.ru
из рабочей среды недоступна.
